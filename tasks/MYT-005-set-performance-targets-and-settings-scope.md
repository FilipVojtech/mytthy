# MYT-005 Set performance targets and settings scope

## Description

Set measurable performance targets and choose the controls for the first graphical settings page.

## Acceptance criteria

- Record numeric performance targets against the baseline and list the controls included in the first settings page.

## Related requirements

- FR-2 · Graphical settings
- NFR-1 · Performance
- NFR-2 · Usability
