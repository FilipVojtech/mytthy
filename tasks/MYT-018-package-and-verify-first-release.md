# MYT-018 Package and verify first release

## Description

Choose a first distribution format. Document installation, launch, and usage, then verify the installation on the target environment.

## Acceptance criteria

- Record the distribution format, document installation and use, and verify the package installs and launches on Fedora KDE Wayland.
- Verify installation on a clean supported desktop. The install must bundle or automatically resolve all application runtime dependencies without requiring the user to install libraries separately.

## Related requirements

- NFR-4 · Native Wayland
- NFR-5 · Dependency independence
